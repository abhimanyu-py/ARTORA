ARTORA

Contemporary Art Gallery HTML Template

Thank you for purchasing ARTORA. This documentation explains how to install, customize and use the template.

1. Getting Started

ARTORA is a static HTML template. No server or database is required to run the basic website.

Simply open index.html in a web browser or use a local development server such as VS Code Live Server.

2. Folder Structure

3. Changing Website Text

Open any HTML file such as index.html, about.html or gallery.html.

Find the text you want to change and replace it with your own content.

4. Changing Images

Place your artwork images inside the images folder.

Then update the image path in the HTML file. 

<img src="images/art-1.jpg"
     alt="Artwork">
Keep the image filename and extension exactly the same as the filename used in your HTML code.

5. Changing Colors and Design

Open: 

css/style.css

You can change colors, fonts, spacing, sizes and layouts from the CSS file.

6. Gallery Filters

Gallery filtering is handled by js/script.js.

Gallery items use categories such as Contemporary, Abstract and Modern.

7. Image Lightbox

Clicking an artwork opens it in a larger lightbox view.

The lightbox also supports previous and next navigation.

8. Contact Form

The contact form includes basic browser validation for required fields and email format.

The included contact form is a front-end demo. To receive real emails, connect it to your preferred form-handling service or backend.

9. Customization

  • Change artwork images
  • Change gallery titles and descriptions
  • Change colors and typography
  • Change navigation links
  • Change contact information
  • Add or remove gallery items

10. Browser Support

ARTORA is designed for modern web browsers including Chrome, Edge, Firefox and Safari.
